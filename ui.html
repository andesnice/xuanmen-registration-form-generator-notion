Notion 資料庫

第一次使用？查看 Notion API 設定教學

這裡需要的是 Notion 的 Installation access token，不是 Notion 帳號密碼。第一次設定約需 3～5 分鐘。

  1. 確認你是工作區擁有者Notion 目前只有 Workspace owner 能建立內部連線；若你不是，請請擁有者代為建立。
  2. 建立 Notion 內部連線前往 Notion 連線設定，按「New integration／新增連線」，名稱可填「通用報名表產生器」，並選對工作區。
  3. 開啟需要的內容權限在 Capabilities 允許 Read content、Insert content、Update content，讓產生器能讀取建立位置、建立資料庫與寫入報名資料。
  4. 複製 Token到 Configuration 找到 Installation access token，按 Copy，貼到下方 Token 欄位。Token 等同密碼，請勿截圖、公開或傳給他人。
  5. 把目標位置分享給連線開啟要放資料的「活動總資料庫」或父頁面，按右上角 ••• → Connections／連線 → Add connection，選取剛建立的連線。新連線預設沒有任何頁面權限，這一步不能省略。
  6. 貼上目標網址在同一個資料庫或頁面按 ••• → Copy link，將整段 Notion 網址貼到下方「建立位置」欄位，不必自己從網址找 32 碼 ID。
✓ Token 已貼入，前後沒有多餘空格
✓ 連線與目標位於同一工作區
✓ 目標頁面已加入該 Connection
常見錯誤快速判斷
  • 401：Token 錯誤、失效或複製不完整，請重新 Copy。
  • 403：連線缺少讀取、插入或更新內容權限。
  • 404／找不到頁面：通常是尚未把目標頁面分享給連線，或選錯工作區。
  • 找不到 32 碼 ID：直接貼完整 Notion 網址即可。
仍有疑問可查看 Notion 官方 Internal connections 教學。
